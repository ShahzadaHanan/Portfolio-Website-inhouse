## JavaScript Modules

### `theme.js`
Reads `localStorage` for saved theme preference (`light` / `dark`). Falls back to `prefers-color-scheme` media query. Sets `data-theme` on `<html>` before paint to avoid flash.

### `main.js`
Core page init: mobile nav toggle, active nav link highlighting, animated stat counters, page-transition veil on internal link clicks, and `html.is-ready` class trigger for hero entrance animations.

### `animations.js`
Uses `IntersectionObserver` to add `.is-visible` to `.reveal` elements as they enter the viewport, triggering fade-up-in transitions defined in `animations.css`.

### `cursor.js` *(Premium — upgraded)*
Custom cursor system with:
- **Dot** — 6 px filled circle, tracks mouse 1:1
- **Spring ring** — 38 px follower with velocity + spring + damping physics
- **Directional squish** — ring stretches in direction of travel, snaps back when still
- **Particle trail** — canvas layer emits fading accent-colored dots behind the cursor
- **VIEW label** — ring expands to 72 px on project cards and shows "VIEW" text
- **Click feedback** — ring snaps small and fills solid on mousedown
- Disabled on touch/coarse-pointer devices and `prefers-reduced-motion`

### `cursor-bg.js`
Renders a canvas behind the hero section with soft glowing ambient color blobs that drift autonomously and one brighter blob that eases toward the cursor (lerp). Colors read live from CSS variables so it works across light/dark themes. Pauses when tab is hidden.

### `smooth-scroll.js`
Single `requestAnimationFrame` loop that lerps `window.scrollY` toward a wheel-accumulated target. Detects external scroll events (keyboard, scrollbar drag) by comparing actual `scrollY` to last written value, then resyncs. Disabled on touch/coarse-pointer devices and `prefers-reduced-motion`.

**Key tuning values:**
- `EASE = 0.13` — how fast page catches up per frame
- `MULTIPLIER = 1.4` — how far each wheel tick moves the target

## CSS Architecture

### `themes.css`
Defines all design tokens as CSS custom properties on `[data-theme="dark"]` and `[data-theme="light"]`. Key variables:

| Variable | Purpose |
|---|---|
| `--bg` | Page background |
| `--fg` | Primary text color |
| `--accent` | Brand accent (amber/gold) |
| `--accent-2` | Secondary accent (teal) |
| `--accent-soft` | Translucent accent for hover fills |
| `--surface` | Card/surface background |
| `--border` | Subtle border color |
| `--dur-fast` / `--dur-slow` | Animation duration tokens |
| `--ease-out` / `--ease-in-out` | Cubic-bezier easing tokens |

### `style.css`
Main stylesheet covering: reset, layout, typography, header/nav, hero, marquee ticker, featured work cards, services grid, stat counters, about bio, skills bars, testimonial cards, contact form, footer, and the premium cursor system.

### `animations.css`
All `@keyframes` definitions and scroll-reveal utilities:
- `fade-up-in` — hero entrance sequence
- `scale-in` — hero art entrance
- `draw-line` — SVG stroke animation
- `pulse-node` — SVG node pulsing
- `float-y` — gentle floating elements
- `marquee` — skills ticker loop
- `veil-in` — page transition overlay
- `.reveal` / `.reveal.is-visible` — scroll reveal base classes

## Features & Interactions

| Feature | How it works |
|---|---|
| **Light / Dark theme** | Toggle button in nav; preference saved to `localStorage`; instant switch via CSS variables |
| **Premium magnetic cursor** | Spring-physics ring with squish, particle trail, VIEW label on cards |
| **Hero canvas background** | Ambient glowing blobs + cursor-reactive light blob on a `<canvas>` |
| **Scroll-reveal animations** | `IntersectionObserver` adds `.is-visible` class triggering CSS transitions |
| **Hero entrance sequence** | Staggered `fade-up-in` animations fire once `html.is-ready` is set |
| **Smooth scroll** | rAF lerp loop intercepts wheel events; natural inertia feel |
| **Skills marquee** | Infinite CSS ticker with `@keyframes marquee` |
| **Stat counters** | JS counts up to target numbers when section scrolls into view |
| **Work page filter** | JS filter buttons toggle card visibility by category |
| **Page transitions** | `.page-veil` overlay animates in/out between internal page navigations |
| **Mobile nav** | Hamburger toggle with `aria-expanded`; closes on outside click |
| **SEO** | Schema.org JSON-LD on home and contact pages; canonical URLs; Open Graph + Twitter Card meta; sitemap.xml; robots.txt |
| **Performance** | No frameworks; fonts preconnected; pixel ratio capped at 2× on canvas; `will-change` on animated elements; `passive` event listeners where possible |
| **Accessibility** | `aria-label`, `aria-current`, `aria-live` for theme announcements; `prefers-reduced-motion` respected across all animations and cursor |
